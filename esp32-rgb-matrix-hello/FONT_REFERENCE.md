# Flight display font reference

Every entry is a 7px-high glyph. `x` means a lit LED, `o` means off; rows are
written from top to bottom, separated by `/`. All normal glyphs are 5px wide.
The bold capital `Y` is the one exception: it is 6px wide.

There are four reference faces below. Bold lowercase is currently an exact
copy of normal lowercase—the firmware does not yet render a separate bold
lowercase face—but it is included as its own editable sheet so we can promote
your edits into a real fourth face when wanted.

## How to send a correction

Reply with the exact face and letter plus its pixels. For example:

```text
bold capital Y (6×7)
xxooxx
oxxxxo
ooxxoo
ooxxoo
ooxxoo
ooxxoo
ooxxoo
```

Use `x` for on and `o` for off. Keep every row the same width and include all
seven rows. I will preserve that width (including any intentional 6px glyphs)
and flash the changed glyphs. You can send one letter, a group, or a photo plus
the grid; the grid is the authoritative version.

## Pixel-perfect PNG round trip

The two scripts in `tools/` make one exact 91×14px black-and-white image for
each alphabet face (13 glyph cells per row × 2 rows). Each cell is 7×7px:
six editable pixel columns and a required black separator at the right.

```bash
python3 tools/font_to_png.py FONT_REFERENCE.md "Bold capitals" bold-capitals.png
python3 tools/png_to_font.py bold-capitals.png "Bold capitals" > bold-capitals-edited.md
```

White is on; black is off. Edit only at actual-pixel resolution—no scaling,
anti-aliasing, or transparent pixels. Keep the seventh/rightmost column of
each 7px cell black. On import, completely black right-side columns are
trimmed, so five-pixel letters stay five pixels wide and a six-pixel letter
such as bold `Y` remains six pixels wide. Send me the returned `.md` or the
edited PNG.
