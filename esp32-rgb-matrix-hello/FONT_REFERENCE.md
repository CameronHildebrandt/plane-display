# Flight display font reference

Every entry is a 7px-high glyph. `x` means a lit LED, `o` means off; rows are
written from top to bottom, separated by `/`. The uppercase faces preserve
their authored widths; notably, normal and bold `I` are 4px wide. The bold
faces also retain their 5px and 6px forms.

There are four reference faces below. Bold lowercase is a separate,
variable-width face and is ready for any display field that requests it.

## How to send a correction

Reply with the exact face and letter plus its pixels. For example:

```text
bold capital Y (6×7)
xxooxx
oxxxxo
ooxxoo
ooxxoo
ooxxoo
ooxxoo
ooxxoo
```

Use `x` for on and `o` for off. Keep every row the same width and include all
seven rows. I will preserve that width (including any intentional 6px glyphs)
and flash the changed glyphs. You can send one letter, a group, or a photo plus
the grid; the grid is the authoritative version.

## Pixel-perfect PNG round trip

The two scripts in `tools/` make one exact 182×7px black-and-white image for
each alphabet face (26 glyph cells on one row), or one exact 70×7px image for
a numeral face (10 glyph cells on one row). Each cell is 7×7px: six
editable pixel columns and a required black separator at the right.

```bash
python3 tools/font_to_png.py FONT_REFERENCE.md "Bold capitals" bold-capitals.png
python3 tools/png_to_font.py bold-capitals.png "Bold capitals" > bold-capitals-edited.md
python3 tools/font_to_png.py FONT_REFERENCE.md "Normal numerals" normal-numerals.png
python3 tools/png_to_font.py normal-numerals.png "Normal numerals" > normal-numerals-edited.md
```

White is on; black is off. Edit only at actual-pixel resolution—no scaling,
anti-aliasing, or transparent pixels. Keep the seventh/rightmost column of
each 7px cell black. On import, completely black right-side columns are
trimmed, so every glyph keeps its intended width (such as the 4px `I` and 6px
`Y`). Send me the returned `.md` or the edited PNG.
